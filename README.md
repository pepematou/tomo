# Tomo

Lector personal de manga, manhwa y (pronto) fanfics. Es un fork de [Mihon](https://github.com/mihonapp/mihon), distribuido bajo la misma licencia Apache 2.0 (ver `LICENSE`).

Tomo usa su propio identificador (`app.tomo`), así que se instala junto a Mihon sin reemplazarlo.

## Instalar

1. Descarga `tomo-vX.Y.Z.apk` desde [Releases](https://github.com/pepematou/tomo/releases/latest).
2. Ábrelo en el celular y permite instalar desde esa app.
3. Para traer tu biblioteca: en Mihon, *Más → Datos y almacenamiento → Crear respaldo*; en Tomo, *Restaurar respaldo* y elige el archivo `.tachibk`.

Tomo no incluye extensiones ni repositorios; cada persona agrega los suyos.
